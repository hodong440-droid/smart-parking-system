# Thuật ngữ

| Thuật ngữ | Giải thích trong phạm vi đề tài |
|---|---|
| Parking lot | Một bãi đỗ xe được quản lý trên nền tảng |
| Parking zone | Khu vực/zone thuộc một bãi xe |
| Parking space | Vị trí đỗ xe cụ thể |
| Gate | Cổng vào, cổng ra hoặc cổng hai chiều |
| Reservation | Yêu cầu giữ suất đỗ trong một khoảng thời gian; không đồng nghĩa xe đã vào bãi |
| Parking session | Lượt gửi xe thực tế, bắt đầu khi xe được ghi nhận vào và kết thúc khi xe rời bãi |
| Check-in / Check-out | Nghiệp vụ ghi nhận xe vào / xe ra |
| Pricing rule | Quy tắc tính phí có hiệu lực theo thời gian và loại phương tiện |
| Invoice | Hóa đơn của lượt gửi xe |
| Payment | Lần ghi nhận/thực hiện thanh toán cho hóa đơn |
| ALPR | Automatic License Plate Recognition – nhận diện biển số tự động |
| OCR | Optical Character Recognition – nhận dạng ký tự từ hình ảnh |
| MQTT | Giao thức publish/subscribe dùng trao đổi thông điệp giữa backend và simulator/thiết bị |
| Mosquitto | Phần mềm MQTT broker trung chuyển thông điệp |
| Node-RED | Công cụ flow-based dùng xây dựng simulator và luồng tích hợp |
| Event idempotency | Xử lý event lặp mà không thực hiện nghiệp vụ nhiều lần |
| ACK | Thông điệp xác nhận một command đã được thiết bị xử lý |
| Resource scope | Phạm vi tài nguyên người dùng được phép truy cập, ví dụ các bãi xe được phân công |
| Modular Monolith | Một ứng dụng backend triển khai thống nhất nhưng chia module nghiệp vụ có ranh giới rõ |
| ADR | Architecture Decision Record – bản ghi quyết định kiến trúc, bối cảnh và hệ quả |
